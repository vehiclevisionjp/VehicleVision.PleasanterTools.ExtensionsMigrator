# ライセンス文書の差し込み部品

`LICENSING.md` と `LICENSE-COMMERCIAL.md` の、ツールごとに変わる部分の部品集。
使い方と節マーカーの規則は [ライセンス](ライセンス.md) の「正本の使い方」にある。

**ここに書いた事実の断定文（Pleasanter 本体を参照していない、DB へ接続しない、など）は、
適用するリポジトリの実態（csproj の参照、通信方式、配置物）で確認してから使う。**
実態と合わない部品は選ばない。合う部品が無ければ、部品を足してから使う（この文書と正本を同じ PR で直す）。

部品は節マーカーごと、そのまま正本へ貼る。マーカーは正本の側に残す。
`〈…〉` は手で埋める箇所で、**埋めたあとに `〈` `〉` を残さない**。

## 書式

- 開始 `<!-- license:begin 節名=ID -->`、終了 `<!-- license:end 節名 -->`。それぞれ 1 行で、前後に別の文字を置かない
- 箇条書きの中に置くマーカーは、前の項目の続きとして 2 文字インデントする（リストを分断しないため）
- ID は半角英小文字とハイフン。`connection` だけは `,` で複数を並べられる（本文は下の順に連結する）
- `free` は自由記述の節。空でもマーカーは残す

## LICENSING.md

### release（リリース状態の注記）

先頭の見出しの直後。公開済みの版が別の提供条件で出ている、または未公開のときだけ使う。

`none`: 注記なし。

```markdown
<!-- license:begin release=none -->
<!-- license:end release -->
```

`unreleased`: 未リリース。

```markdown
<!-- license:begin release=unreleased -->
> 本ソフトウェアは未リリースです。
> 最初のリリースは、この提供条件（デュアルライセンス）で出します。
<!-- license:end release -->
```

`released`: 公開済みの版が AGPL-3.0-or-later 単独で出ている。版は手で埋める。

```markdown
<!-- license:begin release=released -->
> 公開済みの版（〈v0.1.0 など〉）は、受け取った時点の AGPL-3.0-or-later のままです。
<!-- license:end release -->
```

`console`: コンソールアプリで、利用者が自分の環境で実行する。

```markdown
<!-- license:begin usage=console -->
本ソフトウェアはコンソールアプリで、利用者が自分の環境で実行します。
<!-- license:end usage -->
```

`web-service`: Web サービスとして提供する、または提供されやすい。〈…〉には提供する画面・URL などを書く。

```markdown
<!-- license:begin usage=web-service -->
**本ソフトウェアは〈提供する画面・URL など〉を公開する用途であり、
「ネットワーク越しのサービス提供」に該当しやすい**点に注意してください。
改変せずに運用する場合は、改変版のソースコードを提供する義務は生じません。
<!-- license:end usage -->
```

`library`: アプリへ組み込んで使う共通部品。

```markdown
<!-- license:begin usage=library -->
**本ソフトウェアは、各アプリケーションへ組み込んで使う共通部品（ライブラリ）です。
```


### connection（Pleasanter との接続方式）

Pleasanter との関係の節の、箇条書きの 2 項目目（派生著作物ではない）の次に置く。
`api-only` と `none` は単独で使う。ほかは組み合わせられる（例: `connection=api,db-read`）。
連結の順は `api`、`db-read`、`db-same`、`db-convert`、`config-write`。

`api-only`: 標準 Web API だけで通信する。DB へは接続しない。

```markdown
  <!-- license:begin connection=api-only -->
- Pleasanter とは **標準 Web API 越しにのみ通信**します。DB へ直接接続しません
  <!-- license:end connection -->
```

`api`: HTTP（標準 Web API など）で通信する。ほかの方式と組み合わせるときに使う。

```markdown
  <!-- license:begin connection=api -->
- Pleasanter とは **HTTP 越しに通信**します（標準 Web API など、本体が公開するもの）
  <!-- license:end connection -->
```

`db-read`: Pleasanter の DB へ読み取り専用で接続する。

```markdown
  <!-- license:begin connection=db-read -->
- Pleasanter の DB へ **読み取り専用で接続**します。書き込みはしません。
  Pleasanter のコードは読み込まず、DB のスキーマ（テーブルと列）を事実として参照するだけです
  <!-- license:end connection -->
```

`db-same`: Pleasanter と同じ DB へ接続し、読み取り以外の操作も行う。

```markdown
  <!-- license:begin connection=db-same -->
- Pleasanter と**同じデータベースへ直接接続**します。Pleasanter 本体のプログラムは呼び出しません
  <!-- license:end connection -->
```

`db-convert`: 2 つの Pleasanter の DB へ直接接続し、一方（変換元）は読み取りだけ、もう一方（変換先）へは書き込む。Web API は使わない。

```markdown
  <!-- license:begin connection=db-convert -->
- Pleasanter の **2 つの DB へ直接接続**します。変換元は**読み取りだけ**を行い、変換先へは**書き込みます**。
  Pleasanter の Web API は使わず、Pleasanter 本体のプログラムも呼び出しません
  <!-- license:end connection -->
```

`config-write`: Pleasanter の設定ファイル置き場へファイルを書き出す。

```markdown
  <!-- license:begin connection=config-write -->
- Pleasanter の設定ファイル置き場（`App_Data/Parameters/` 配下など）へ**ファイルを書き出します**。
  Pleasanter 本体のプログラムは呼び出しません
  <!-- license:end connection -->
```

`none`: Pleasanter と通信も接続もしない。

```markdown
  <!-- license:begin connection=none -->
- 本ソフトウェア自体は **Pleasanter と通信せず、Pleasanter の DB へも接続しません**
  <!-- license:end connection -->
```

```javascript
                // license:begin cla-intro=triple
```
